# Dipo development

Use Node.js 24 and pnpm. Run `pnpm install` followed by `pnpm dev` and open http://localhost:3000. Run `pnpm build` to check the production build.

See [sales setup](sales.md) for Supabase configuration and offline verification. The dashboard uses a one-column layout on phones, two columns on tablets, and three on wider screens.

Place licensed Mosvita Regular and Bold webfonts in `public/fonts/mosvita.woff2` and `public/fonts/mosvita-bold.woff2`. Until they are supplied, the browser displays its default font.
